# Timer

A pomodoro timer for tracking work sessions. Design a **Plan** — a queue of sessions of different types, each with its own color — and start it in one go, or run a simple endless **Flow**.

Status: early development. See the [specification](docs/spec.md) and the [roadmap](docs/roadmap.md).

## Requirements

- Linux
- Python 3.12+ with Tkinter
- [uv](https://docs.astral.sh/uv/)

## Run

```
uv run timer
```

## Test

```
uv run pytest
```
